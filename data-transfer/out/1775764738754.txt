## Abstract

Toolbox Companion (TBC) is a lightweight local launcher with a browser UI. Users see configurable pages of tiles; each tile opens a URL, launches a program or folder path, or runs several actions in sequence. Paths use shared macros (e.g., well root, startup folders) with optional per-machine overrides via environment variables. Configuration is stored in a single JSON file with a built-in editor. TBC can trigger other processes and sequences, and exposes simple REST endpoints for external calls. Errors are logged locally in SQLite for troubleshooting.

In current field and remote operations, engineers repeatedly navigate across folders, applications, and web resources to access routine workflows. This introduces variability, delays, and occasional path errors, particularly across different wells and machines.

TBC standardizes access through a configurable tile interface, reducing repeated navigation and improving execution consistency. The solution operates locally with no network dependency and is portable as a folder copy.

Expected benefits include improved time-to-action, reduced navigation variability, more consistent execution across shifts, and fewer path-related errors.

## Introduction

Toolbox Companion was conceived to give engineers and office staff a consistent, fast way to reach the same URLs, executables, and directory trees they use every day, without hunting through Start menus or inconsistent shortcuts.

**Background:** In current operations, engineers spend significant shift time navigating to well folders, launching specific applications, and accessing recurring web resources (SWI, reports, dashboards). Each engineer may develop their own navigation patterns, leading to variability across shifts and locations.

**Technology stack:** Node.js serving static HTML/CSS/JavaScript and JSON configuration.

**Stakeholders:** End users who define tiles and macros for their rig or office; IT or support staff who may read error logs; operations leadership interested in execution consistency; any automation that calls the HTTP API.

**Related work:** Generic launchers and enterprise portals exist. TBC differs by staying small, file-driven, portable (optional bundled Node.js), and easy to deploy as a folder copy. It runs independently of other integration frameworks.
